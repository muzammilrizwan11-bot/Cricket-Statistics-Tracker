# 🏏 Cricket Statistics Tracker

A complete Python-based Cricket Statistics Tracker developed for Cedar College.

This project allows coaches and management to store, update, search, and analyze cricket statistics for all players while maintaining permanent records using JSON.

---

## ✨ Features

- Secure Login System
- Permanent JSON Database
- Add New Players
- Update Match Statistics
- Search Players
- View Complete Player Profiles
- Team Statistics
- Campus Statistics
- Leaderboards
- Export Reports
- Delete Players
- Automatic Batting Calculations
- Automatic Bowling Calculations
- Match History Tracking
- Input Validation
- Modular Python Code

## 💾 Data Storage

All player records are stored inside:

```
players.json
```

Statistics remain available every time the program is restarted (when run in a Python environment that supports file storage).
